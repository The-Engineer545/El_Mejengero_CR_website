# MISSION

**Goal:** Aprender a programar la lógica del frontend con JavaScript puro (Vanilla JS) para el proyecto "El Mejengero CR".

**Context:** 
- Proyecto del curso Programación III, Universidad Nacional (UNA) Sede Chorotega.
- Fecha de entrega: Sábado 3 de Octubre de 2026.
- Equipo: Josué, Darío, Luis, Dereck.

**Key Requirements (Rúbrica de 100pts):**
1. Cargar datos dinámicamente desde un `productos.json` usando `fetch`.
2. Manipular el DOM usando `document.createElement()` (no usar `innerHTML` indiscriminadamente).
3. Implementar un carrito de compras funcional (cálculos matemáticos y persistencia).
4. Validar formularios con Expresiones Regulares (Regex) para cédulas y teléfonos de CR.
5. Defender el código en la presentación final (cada miembro debe entender perfectamente qué hace cada línea).

**Motivation:** Josué quiere aprender a hacer las cosas por sí mismo, rechaza que la IA haga el trabajo por él, y busca entender el "por qué" de cada comando y línea de código para convertirse en un mejor desarrollador y asegurar la nota máxima del equipo.
